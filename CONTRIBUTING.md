# Contributing

1. Branch from `main` using `feature/*`, `fix/*`, or `chore/*`.
2. Use Conventional Commits (`feat:`, `fix:`, `chore:`).
3. Open a pull request with scope, screenshots where applicable, and test evidence.
4. Require successful CI before squash merge. Do not force-push `main`.
5. Deploy production only from `main`; Cloudflare previews are for review.
6. Never commit private keys, seed phrases, tokens or production secrets.
